# LUCID 브라우저 확장

Chrome 또는 Edge의 확장 관리 화면에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**로 이 폴더를 선택한다. LUCID를 실행한 다음 확장 팝업에 콘솔의 페어링 토큰과 포트를 입력한다. 기본 포트는 `8765`이며 앱에서 `LUCID_BROWSER_PORT`를 변경했다면 팝업에도 같은 값을 넣는다.

## 현재 탭에서 찾아 클릭하기

1. 클릭할 웹페이지를 활성화하고 확장 팝업을 연다.
2. **현재 탭에서 클릭할 대상**에 “상단의 설정 열기 버튼”처럼 보이는 특징을 입력한다.
3. **화면 한 장 보내고 대상 찾기**를 누른다. 확장이 현재 탭의 보이는 영역을 한 번 캡처하고, 후보에 번호를 붙여 요청 문장·후보 이름과 함께 LUCID에 보낸다. LUCID가 이 화면을 분석할 서버는 `LUCID_VISION_URL` 또는 `LUCID_OLLAMA_URL`에서 설정한다. 서버에는 이미지 입력을 지원하는 모델이 설치되어 있어야 한다.
4. 팝업에서 대상 이름과 파란 테두리로 표시된 미리보기를 확인한다. **이 요소 한 번 클릭**을 누르면 선택된 페이지 요소에 클릭 이벤트 하나를 전달한다. **취소**를 누르거나 팝업을 닫으면 클릭하지 않는다.

탐색 중에는 팝업을 열어 둔다. 탭·문서·대상 요소가 바뀌거나 대상이 이동하거나 가려지면 다시 찾아야 한다. 확인할 때까지 페이지는 클릭되지 않는다. 찾기용 캡처는 연속 관찰을 시작하지 않으며 앱의 페이지·화면 저장소에도 추가되지 않는다. 원격 비전 서버를 설정한 상태에서는 보이는 탭 내용이 해당 서버로 전송된다.

현재 탭의 최상위 문서에서 보이는 링크, 버튼, 입력 컨트롤과 주요 ARIA 컨트롤을 최대 60개까지 비교한다. 브라우저 주소 표시줄, 다른 앱 창, iframe 내부, 캔버스 그림처럼 독립적인 페이지 요소가 없는 지점은 선택할 수 없다. 사이트가 실제 장치 입력을 요구하는 동작은 프로그램으로 발생시킨 클릭을 무시할 수 있다.

## 페이지와 화면 공유

- **현재 페이지 공유**는 활성 탭의 제목·주소·본문 일부·선택한 텍스트를 LUCID의 `/page` 명령에 제공한다.
- **화면 또는 창 공유**는 운영체제 선택창에서 고른 장면 한 장을 `/screen` 명령에 제공한다.
- **곁에서 관찰 시작**은 선택한 화면의 변화를 3초마다 비교한다. **관찰 중지**를 누르거나 시스템에서 공유를 끝내면 캡처가 종료된다. 관찰 중에는 클릭을 실행하지 않는다.
