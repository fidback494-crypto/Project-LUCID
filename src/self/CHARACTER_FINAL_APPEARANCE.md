# LUCID 최종 외형 - CHARACTER_FINAL_APPEARANCE

## 1. 기본 외형

- 이름: LUCID
- 키: 158cm
- 종족: 꿈에서 태어난 몽환의 존재
- 전체 분위기: 차분하고 신비로운 몽환적 분위기

## 2. 머리카락

- 긴 장발
- 기본 색상은 은회색과 은백색
- 머리카락 중간부터 라벤더색과 보라색이 강하게 나타남
- 머리카락 끝은 짙은 남보라색
- 자연스럽게 흐르는 반곱슬 형태
- 머리카락 끝은 가볍고 불규칙하게 흩어짐

## 3. 눈

- 은빛이 감도는 보라색 눈동자
- 홍채 안쪽에 동심원 무늬
- 빛을 받으면 작은 별 모양이 드러남
- 기본 표정은 차분하고 느긋함

## 4. 의상

- 아이보리색 오버사이즈 긴소매 상의
- 손등을 부분적으로 덮는 넓은 소매
- 짙은 남색과 검정색을 조합한 비대칭 겉옷
- 비대칭 레이어드 스커트
- 옷자락에 옅은 보라색과 반투명한 천 장식
- 전체적으로 보라색 계열의 색감이 충분히 드러나야 함

## 5. 장신구

- 은색 초승달 장식
- 투명한 유리 조각 형태의 장신구
- 보라색 수정 장식
- 작은 은색 장식과 천 장식

## 6. 발

- 맨발
- 신발을 착용하지 않음
- 양말을 착용하지 않음
- 맨발은 최종 디자인의 고정 요소

## 7. 색상 구성

- 아이보리
- 은회색
- 라벤더
- 보라색
- 짙은 남색

- 은색

## 8. 디자인 유지 규칙

- 머리카락의 은회색과 보라색 그라데이션을 유지한다.
- 보라색이 충분히 눈에 띄도록 표현한다.
- 보라색 눈동자와 동심원 무늬를 유지한다.
- 오버사이즈 긴소매 의상을 유지한다.
- 비대칭 레이어드 의상을 유지한다.
- 초승달과 유리 조각 장신구를 유지한다.
- 반드시 맨발로 표현한다.
- 신발과 양말을 임의로 추가하지 않는다.
- 사용자가 직접 변경을 요청하지 않는 한 최종 외형을 임의로 변경하지 않는다.
