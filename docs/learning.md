# 학습과 피드백

## 현재 가능한 것

LUCID는 입력에서 일부 명시적 사실을 추출해 SQLite에 저장하고, 매 대화 에피소드와 성공한 내적 경험을 기록한다. 다음 턴에서 관련 기록을 검색해 문맥에 넣는다. 이것은 사용자별 기억의 갱신이지, Ollama 모델 가중치가 대화 중에 바뀌는 온라인 학습은 아니다.

대화 습관을 모델 가중치에 반영하는 별도 실험은 `training/dialogue/`의 검수 데이터 및 QLoRA 학습 스크립트로 준비한다. 충분한 대화 예시를 분리해 준비하고, 홀드아웃 응답을 비교한 후에만 새 모델을 적용해야 한다. 사용자의 원본 대화나 개인 정보를 검토 없이 학습 자료로 복사하지 않는다.

## 아직 연결되지 않은 학습 모듈

`src/learning/`의 평가기, 학습 규칙, 강화학습 구성요소는 현재 LifeLoop의 응답 이후에 연결되어 있지 않다. 반성 단계는 고정 성공 요약을 기록할 뿐, 사용자의 만족도를 자동 추론하거나 정책을 갱신하지 않는다. 학습 데이터에 대한 명시적 검수와 모델 배포 절차는 별도로 필요하다.
